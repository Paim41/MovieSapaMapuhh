05 / GOOD TO KNOW

QUESTIONS,
ANSWERED.

The details that matter when you're choosing a self-hosted setup.

Does MovieSapaMapuh include movies or TV shows?

No. It is a server and interface for media discovery and streaming through configured third-party sources and files you are permitted to access. No hosted movie collection is included.

Is the APK ready for everyday stable updates?

The current publicly available v1.0.5 APK is a debug-signed testing preview. Debug signing can vary across builds, so upgrades may fail if signatures differ. Back up data before replacing an installation.

Do I need multiple Telegram bots?

No. The app supports automatic guest provisioning or a supplied Telegram bot token. Bot Pool can manage more than one session for rotation or fallback, but adding bots does not automatically make more titles available.

Will it work on my laptop or TV?

The Android device hosts the server and its web interface. Other clients may use compatible addon endpoints or the local network address when supported, but Wi-Fi client isolation, firewall or mobile OS restrictions can prevent LAN access.

How does the Si Youyou character work?

The current MovieSapaMapuh design uses a small four-frame walking loading animation and a pointer-only desktop cursor asset. The original floating interactive pet and its settings were removed.

Is this an official PencariMovie release?

No. MovieSapaMapuh is a customized fork built on PencariMovie Server. Original project attribution, license notices and upstream credits are preserved.
